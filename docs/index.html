Freally MIDI Master

Artist-accurate MIDI, generated onto the track you are already working on.

Drums, melodies, countermelodies, 808s, chords and full song arrangements — generated in the style of specific artists, as original MIDI, in your project's own key and tempo. Free, offline, and 100% AI-free.

🎤

Artists, not genres

Most generators think in genres. "Trap" is not "Metro Boomin," and no mainstream tool has heard of OsamaSon. Type a name and get patterns carrying that artist's actual signatures.

🎚️

It follows your DAW

The plugin reads the host's tempo and time signature every block, so trap authored at 140 comes out at 92 in a 92 BPM project. Pin a tempo and yours wins instead.

🥁

Five generators, plus Song Mode

Drums, Melody, Countermelody, Bassline and Chords — plus Song Mode, which is not a sixth generator but an arrangement that fills all five in.

🎯

Notes land on the track

No file to drag, no folder to hunt for. The plugin emits MIDI where you inserted it, in the host's own time.

🔁

Reproducible by seed

Every generation has a seed. Copy it, paste it, get the exact same beat back — on any machine, on any day. Determinism is enforced by the test suite.

🔒

No AI, no account, no cloud

No models, no training data, no inference, and no network calls during generation. No login and no telemetry. Everything happens on your machine.

Status — it is a plugin now

Freally MIDI Master began as a desktop app; v0.2.0 was that build. As of 29 July 2026 the desktop app is retired — it is no longer built or released. Nothing already installed stops working; it simply stops finding updates.

It is now a CLAP plugin, with VST3 and AU projected from it — not for the format's sake, but because a plugin is handed the host's tempo, time signature and playhead. A generated pattern lands in the song you are actually writing, instead of at whatever tempo the artist happens to be authored at.

Where it has been loaded

It loads and generates in Ableton Live 12 (VST3) and FL Studio (CLAP). Reaper, Bitwig and Logic are not yet tested. The standalone build runs the same plugin in its own window with no DAW involved.

Windows macOS Linux (editor in progress)

⛔ There is nothing to download yet, and there will not be until 1.0. No beta, no preview build, no early access. A plugin that half-works inside somebody's session is worse than one that is not there — so it ships when the QA matrix is green on every host and every OS, and not before. Until then the source builds: see Building from source.

The engine is rule-based, not trained

There is no AI in this product. No models, no training data, no inference, no network calls during generation. The engine is deterministic procedural code reading hand-authored style parameters derived from published research.

That is a legal architecture as much as a technical one: nothing here is copied MIDI, sampled audio, or a transcription of anyone's record, and there is no feature that recreates a specific song. Artist names are descriptive style references only.

The music you make with it is yours, with no royalty and no attribution requirement. Freally MIDI Master itself is proprietary and source-available — you may read the source, build it and run it locally, but not redistribute it. It is not open source.

Privacy

No accounts. No telemetry. Nothing about you, your projects or your output is ever transmitted. Generation, playback, import and export are entirely local.

  • A launch-time update check that fetches one small version file and prompts before doing anything.
  • Crash reports, written locally, shown to you in full, and sent only if you click to send them.

Those two are the only outbound connections that exist.
